## Review
This machine will be my biggest regret of the season.
It starts with a valid set of credentials, and I was lucky enough to find the path to the user flag almost instantly, but then I got stuck for two days on the root flag.
In the end, I had all the pieces; I just missed one configuration step to execute the final attack.
It's a fun machine that features some attacks you don't usually encounter, revolving around Active Directory and Read-Only Domain Controllers.


**Personal Rating:** ⭐⭐⭐⭐ (4.0/5)

**Recommended for:** Those who want to deepen their knowledge of Active Directory attacks, particularly around RODC environments, Kerberos ticket abuse, and delegation techniques.
